CS-360 Module Eight Journal: Portfolio Reflection

Application Requirements and Goals

For Project Three, I developed a Weight Tracking application using Android Studio. The goal was to create a functional mobile application that would allow users to monitor and manage their weight records over time. The application needed to support user registration and login, adding weight entries, viewing previously recorded information, and deleting entries when necessary. It also included an SMS permission feature. I wanted the application to be straightforward so that users could record and review their information without unnecessary complications.

User Interface Design

When designing the application, I focused on creating screens that were easy to understand and navigate. The application included login and registration screens, a home screen, weight entry forms, and a history section. I used navigation buttons and input fields to help users move between different functions. One important consideration was ensuring that users could access the features they needed without confusion. I also tested the application in different screen orientations to ensure that the text and layout adjusted appropriately. This experience reinforced the importance of designing around the user’s needs rather than simply making the application look complete.

Coding Approach and Strategies

My development approach involved breaking the application into smaller components and working on them individually. I used Kotlin in Android Studio and implemented local database functionality to store and retrieve weight records. Rather than attempting to complete everything at once, I worked through individual features, tested their behavior, and made adjustments when necessary. I also learned the importance of keeping the code organized and understanding how different parts of the application interact. These strategies will be useful in future projects because they make development and troubleshooting more manageable.

Testing and Functionality

Testing played an important role throughout the development process. I used the Android emulator to verify that the application launched successfully and that its features behaved as expected. I tested the login process, navigation, adding weight entries, saving information, and viewing recorded data. I also checked how the application responded when the device orientation changed. One issue I encountered involved the Add Weight button on the home screen, which initially did not respond even though the same feature worked through the navigation menu. After reviewing and correcting the issue, I was able to improve the application’s functionality. This taught me that a successful build does not necessarily mean every feature works correctly.

Challenges, Successes, and Lessons Learned

One of the biggest challenges I encountered was making sure the different components worked together consistently. At times, a feature appeared to work in one part of the application but behaved differently in another. Resolving these issues required patience, testing, and a willingness to revisit my earlier work. One of my greatest accomplishments was seeing the application run successfully after working through those challenges. I was particularly pleased with implementing the weight entry functionality and seeing information saved and displayed within the application.

This project strengthened my understanding of mobile application development and gave me practical experience that I can continue building on. As I approach the completion of my bachelor’s degree in computer science, I intend to apply these skills to future software projects and continue improving my ability to create applications that are functional, reliable, and user-friendly.
